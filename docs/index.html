Engineered for accuracy and privacy.

Built with native low-level keyboard hooks and high-pass audio filtering. Zero accounts, zero tracking.

Dedicated Push-to-Talk

Standard mode triggers exclusively on Caps Lock to prevent accidental activations. Optional single Control mode available in custom settings.

Noise Suppression

16 kHz Mono PCM audio pipeline with 80 Hz high-pass filter and pre-emphasis. Cleans fan noise, HVAC rumble, and room reverberation.

Hindi & Hinglish Support

Seamlessly handles mixed Hindi and English speech with real-time Devanagari-to-Roman transliteration and hallucination loop suppression.
