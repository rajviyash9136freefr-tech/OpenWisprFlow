Engineered for accuracy and privacy.

Low-level OS input hooks, adaptive noise suppression, and zero telemetry.

Low-Level Push-to-Talk

Hooks at the Windows kernel level via SetWindowsHookEx to intercept Caps Lock without toggling keyboard casing. Includes single-key F8 and Ctrl+Space fallbacks.

Adaptive Noise Filtering

85 Hz Butterworth high-pass filter strips PC fan rumble and AC hum. 400ms rolling circular pre-roll buffer ensures the first syllable is never clipped.

Hinglish & Dual Script

Intelligently transcribes natural mixed Hindi and English speech with real-time Devanagari to Roman transliteration options and repetitive loop filtering.
